STEELTAKEOFF AI — LOCAL ESTIMATING WORKSPACE
==========================================

WINDOWS
1. Install Python 3.11 or newer and select Add Python to PATH.
2. Download https://github.com/shahilavneel-dev/New/archive/refs/heads/main.zip
   Sign in to GitHub if required. Right-click the ZIP and choose Extract All.
   Open the extracted application folder in Documents or another writable folder.
3. Double-click START_STEELTAKEOFF.bat. Internet is required for the first package installation.
4. Keep the command window open. If your browser does not open, enter http://127.0.0.1:8765.

Do not run the launcher from inside the ZIP. Customer drawings and saved estimates
are not included in this application download.

Your projects, revisions, settings and uploaded drawings are stored in app_data.
Use Dashboard > Download full backup regularly. Project JSON alone does not include PDFs.

Start with New enquiry. Use Settings to enter verified section weights and edit rates.
Review and approve PDF candidates before import. Unknown dimensions and weights stay unknown.
Missing required costs make profit incomplete. Review all assumptions before quoting.

Excel and PDF reports contain INTERNAL buying costs and profit. The customer email is separate
and editable; the application never sends it. Optional AI requires a separately billed API key
and explicit approval of the selected information before transmission. Core features work locally.

Read README.md for the sample drawing walkthrough, backups, optional OCR, testing and limitations.
This release was tested on Linux/Chromium. Please check the launcher on your Windows computer.
